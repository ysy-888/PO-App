      This publishes application code only. Test and production Google Sheets stay separate — no data or settings are copied.

      3. Push backend to production Apps Script: npm run push:prod then update the Web app deployment (New version) in the Apps Script editor.
      4. Switch to Live Mode, Refresh, and verify production.

      See DEPLOY.md in the repo for full setup and troubleshooting.
